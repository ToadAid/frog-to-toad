# License Recommendation (decision reserved for the principal)

This repository has no LICENSE file yet. Choosing a license is the principal's decision; this document records the recommendation and reasoning for that decision.

## Recommendation: MIT License

Reasoning:

- The genesis cut is documentation — principles, architecture, process. A permissive license maximizes the chance the *ideas* (bounded autonomy, evidence-first operation, memory-as-inheritance) get reused, which is the point of publishing them.
- MIT is short, universally understood, and compatible with essentially everything.
- Attribution matters to this project: the MIT notice preserves attribution in derivatives.

## Alternative considered: Apache-2.0

- Better if/when the repo carries real code with patent concerns. Heavier text, more formality.
- A reasonable future upgrade if code lands here; harder to justify for a docs-only cut.

## Alternative considered: CC-BY-4.0

- Designed for creative and documentation works; arguably the most precise fit for a docs-only repo.
- Less familiar to the developer audience this repo most wants to reach; some tooling treats it awkwardly for code-adjacent projects.

## What was deliberately not done

- No LICENSE file was added — applying a license unilaterally would exceed the agent's authority. The recommendation is advisory; the choice (and any later change) is the principal's.
